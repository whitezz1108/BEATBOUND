# BeatBound audio understanding V2 -- optional heavy dependencies
#
# The V2 analyzer (analyze_music_v2.py) is layered so that these are OPTIONAL.
# Without them the pipeline still runs: stems and melody report
# available: false, analysisMeta.backends records why, and --fast skips them
# entirely. Nothing below is required for the editor to open a song.
#
# Install the core (needed by both analyze_music.py and analyze_music_v2.py):
#
#     pip install -r requirements.txt
#
# Then, to enable the full pipeline:
#
#     pip install -r requirements-audio.txt
#
# ---------------------------------------------------------------------------
# Verified working combination
# ---------------------------------------------------------------------------
# Python 3.12 on Windows 11, as installed and exercised end to end:
#
#     librosa==1.0.0  numpy==2.5.3  scipy==1.18.1  soundfile==0.14.0
#     torch==2.14.0   demucs==4.1.0
#     onnxruntime==1.30.0  basic-pitch==0.4.0  resampy==0.4.3
#
# Two Windows-specific traps, both worked around below:
#
# 1. `pip install basic-pitch` fails on Python 3.12 with
#       BackendUnavailable: Cannot import 'setuptools.build_meta'
#    because its `tensorflow<2.15.1` marker has no py3.12 wheel, so pip falls
#    back to building `numpy<1.24` from source. Installing with --no-deps and
#    adding the pure-python runtime dependencies by hand avoids the whole chain.
#    The ONNX backend is then selected automatically, since TensorFlow, CoreML
#    and TFLite are all absent.
#
# 2. basic-pitch pins `resampy<0.4.3`, but resampy 0.4.2 imports `pkg_resources`,
#    which setuptools 84 removed. resampy 0.4.3 is the fix; it is API-compatible
#    for the one call basic-pitch makes (resample(y, 22050, 44100)).
#
# ---------------------------------------------------------------------------
